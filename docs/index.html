Comment copier un SMS ?

  1. Ouvrez le SMS et appuyez longtemps sur le message (sans toucher le lien).
  2. Choisissez Copier.
  3. Revenez ici, appuyez longtemps dans la case blanche, puis Coller.

Les 3 règles d'or

  1. Un organisme sérieux ne vous demande jamais un code, un mot de passe ou un numéro de carte par SMS ou email.
  2. Plus un message est urgent, plus il faut se méfier.
  3. En cas de doute, appelez vous-même l'organisme, avec le numéro que vous connaissez déjà.
